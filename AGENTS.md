# Project language decision

Before building or evaluating any new AI feature, confirm the language of user inputs, prompts, reference answers, interface text, and instructor-facing materials. If the user has not specified a language, ask one explicit question before preparing data or running tests. Never infer the input language from the user's chat language.

For this submission, the current repository tree is intended to be English-only. The recorded formal scores belong to the earlier Chinese-input experiment at commit `a39e3fc`; translating its inputs does not turn those scores into English-input results. Keep that distinction explicit in reports and demonstrations. Do not rerun or relabel the formal evaluation without the user's authorization.
