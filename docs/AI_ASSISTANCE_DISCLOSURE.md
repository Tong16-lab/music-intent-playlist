# AI-assistance and data-provenance declaration

This declaration is the sole teacher-facing location for assistance disclosures. The author, Niu Tong, remains responsible for the submitted work, source checks, listening judgments, approved answers, interpretation of results, and final presentation.

- On 2026-10-01, the author used **Claude Sonnet 5.5** to draft the 42 constructed Chinese user requests and initial intent-field examples. The recorded prompt was: “依据文档内容，给我42条‘歌曲人工标签’中的表格示例，注意不要遗漏‘原话或脱敏文本’这一条” (English rendering: “Using the document, give me 42 table examples for the song-annotation section; do not omit the original or de-identified utterance”). The author reviewed the resulting requests and approved V2 answers. These requests were not obtained from 14 or any other number of actual participants; the number of recruited participants was **zero**. Persona IDs are fictional.
- On 2026-10-01, the author used **Kimi K3** to draft initial per-track listening labels. The recorded prompt was: “帮我听文档中链接里的歌曲，并按照‘歌曲人工标签’部分的人工听评标准表格，对这些歌曲进行标签” (English rendering: “Listen to the songs linked in the document and label them using the song-annotation table and listening criteria”). That prompt does not establish that the service actually accessed and listened to the linked audio. The author separately listened to and reviewed all 35 tracks and melody-change time points on 2026-10-01. `verified` denotes that author review only; it does not claim independent annotators or objective truth.
- **Codex** assisted with design discussion, code and test scaffolding, document drafting, evaluation diagnostics, and English submission text. The author reviewed the project decisions and the completed listening tables. The runtime model evaluated in the project was **Gemini 3.5 Flash Lite via OpenRouter**; it is distinct from the tools used in preparing the dataset and repository.

The development/test inputs, gold answers, catalog, and reports should be read with those origins in mind. No generated request is represented as a verbatim statement by a real user, and no initial label draft is represented as a measurement. Raw Chinese test inputs are retained to preserve the actual evaluated task; English explanatory documents are translations or summaries, not a replacement test set.
